# 概要
- Web上で触れるシェーダーを用いたペイントソフトを作りたい。
- ゴッホのような絵の具をべったり乗せたような厚めの油彩を再現したい。
  - キャンバス上で法線テクスチャをプロシージャルに生成し、光源を当てて凹凸感を再現する。

# 注意点
- 単一責任の原則を意識してコーディングする。
  - 無理にファイルを1つにしようとせず、適切にコンポーネントを分割する。
- レスポンシブデザインを心がける。

# 構想（メモ程度）
1. キャンバスのデータ構造
- ディファードレンダリング的に、ストロークのインデックス（32bit、回数を数えて採番）、各ピクセルでの最新ストロークの各フレームでの中心位置（座標(x, y)で16bit×2）、速度、加速度（各座標(x, y)合わせて(8bit×2)×2）を3枚のテクスチャで保持します。色は何も加工しない固有色テクスチャとして保持します。全体として4枚のテクスチャを保持します。
- これらの情報から法線テクスチャをいい感じに生成し、平面ポリゴンに色テクスチャと法線テクスチャを反映する。
2. 法線生成
- これは先ほどの情報があればシェダーで試行錯誤でき、根幹のデータ構造には大した影響はないと考えられるため後ほど考える。
3. 入力補間とフレームレート依存の処理
- その他の処理が重くなることが予想できるため、とりあえず線形補間で考える。
4. 光源（Lighting）と配置固定
- Directional Lightの斜め放射で試す。
5. Undo / Redoとテクスチャのメモリ管理
- テクスチャ解像度は1024px×1024px固定を想定している。
- 「テクスチャを丸ごとコピー保持」で回数を5回程度に絞る
6. キャンバスの解像度とデバイスピクセル比
- Nearest-Neighborで拡大縮小してそのまま表示
