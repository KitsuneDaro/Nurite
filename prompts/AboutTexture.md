- 必要なテクスチャ情報
    - メタ情報テクスチャ
        - 入力
            - 現在のストロークID(1から始まる、0は初期値)
            - セグメントID(0~4095)
            - セグメントIDが4096に達した場合はストロークを終了する
            - セグメントの各情報
            - ブラシ形状(0~7の番号で管理)
            - ブラシサイズ(1px~255pxまで)
        - 処理
            - 該当する更新範囲を入力情報を関数に入れて求める
            - その範囲にストロークIDとセグメントIDを入れる
        - 各ピクセル出力(vec4)
            - ストロークID(20bit、非負整数)
                - ストロークごとにユニーク、その時の描画回数に一致する
            - セグメントID(12bit、0~4095)
    - 色テクスチャ
        - 入力
            - メタ情報テクスチャ
            - 現在のストロークID
            - セグメントID
            - 色(8bit×4、RGBA)
        - 処理
            - メタ情報テクスチャとストロークID・セグメントIDが一致する部分だけ更新
            - 入力された色で塗りつぶす
        - 各ピクセル出力(vec4)
            - 色(8bit×4、RGBA)
    - 描画状況テクスチャA
        - 入力
            - メタ情報テクスチャ
            - 現在のストロークID
            - セグメントID
            - ストローク終端位置（各座標0~1023px）
            - ブラシ形状ID(6bit)
            - ペイントスタイルID(6bit)
        - 処理
            - メタ情報テクスチャとストロークID・セグメントIDが一致する部分だけ更新
            - 入力位置とセグメントIDで塗りつぶす
        - 各ピクセル出力(vec4)
            - 位置(10bit×2、非負整数)
            - ブラシ形状ID(6bit、非負整数)
            - ペイントスタイルID(6bit、非負整数)
            - ブラシ形状ID: 未描画=0、丸筆=1、平筆=2、四角筆=3
            - ペイントスタイルID: 未描画=0、ノーマル=1、油彩=2、水彩=3
    - 描画状況テクスチャB
        - 入力
            - メタ情報テクスチャ
            - 現在のストロークID
            - セグメントID
            - 速度(各座標が符号あり整数8bitを超える場合はclamp)
            - 加速度(各座標が符号あり整数8bitを超える場合はclamp)
        - 処理
            - メタ情報テクスチャとストロークID・セグメントIDが一致する部分だけ更新
            - 速度と加速度で塗りつぶす
        - 各ピクセル出力(vec4)
            - 速度(8bit×2、整数)
            - 加速度(8bit×2、整数)
    - 描画状況テクスチャC (RGBA8)
        - 入力
            - メタ情報テクスチャ
            - 現在のストロークIDとセグメントID
            - セグメントごとの縁距離とブラシサイズ
            - ストローク中の上書き縁距離一時テクスチャ
        - 処理
            - メタ情報テクスチャとストロークID・セグメントIDが一致する範囲だけ更新
            - セグメントごとの距離場を最大値で合成し、隣接セグメントの継ぎ目を抑える
            - 四角筆は各セグメントで丸筆と同じ線分距離を計算し、ストローク中の各点を滑らかにつなぐ
            - 四角筆のストローク終了時にだけ始点・終点の進行方向側の外側を追加計算し、方向追従設定に応じた回転正方形の軸マージンで距離を求める
            - MAX縁距離(幾何距離の2倍、0~255px相当)を8bitで保存し、MAXブレンドで既存値と比較する
            - 上書き縁距離は別の8bitテクスチャにストローク中MAXブレンドで蓄積する
            - 各セグメント追加時、一時テクスチャで描画されたセグメント範囲の画素だけ上書き縁距離チャンネルへ完全に上書き合成する。過去のストロークの上書き縁距離とはMAX合成しない
            - 四角筆の始点・終点補正も同じ仕組みで即時に上書き距離へ反映する
            - ブラシサイズを0~255の整数値で8bit保存し、MAXブレンドで保持する
            - ポインター軌跡上をブラシサイズ相当、縁を0とし、その間を距離に応じて補間する
            - 新しいストロークでも消去せず、前ストロークまでの値とMAXブレンドで保持する
        - 各ピクセル出力(vec4)
            - R: MAX縁距離(8bit、幾何距離の2倍を0~255px相当で表す)
            - G: 上書き縁距離(8bit、幾何距離の2倍を0~255px相当で表す)
            - B: ブラシサイズ(8bit整数値、1~255px)
            - A: 未使用
    - 油彩表面マップ (派生テクスチャ)
        - 描画状況AのペイントスタイルIDが油彩(2)のピクセルだけ深度を生成
        - 描画状況CのMAX縁距離を `dmax`、上書き縁距離を `doverride`、ブラシサイズを `s` とし、`d = 0.2 * dmax + 0.8 * doverride`、`x = clamp((s - d) / s, 0, 1)` とする
        - ridgeは距離 `r = clamp(s - d, 0, s)` を使い、`abs(sin(πr / λ))` で生成する。波長 `λ` はpx単位の定数（現在5px）で、ブラシサイズによらず一定周期になる
        - 深度プロファイルは `ridge * (0.25 + 0.75 * abs(cos(πx)))`。ブラシ中心側に浅い谷、その両側に盛り上がりができ、縁では深度0になる
        - 深度の隣接ピクセル差から接線空間法線マップを生成し、キャンバスの表示Planeへ法線マップ・粗さマップとして適用する
        - これらは描画状況A/Cから再生成し、Undo/Redo後にも表示中の履歴に合わせて更新する
